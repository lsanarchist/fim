# Джерела та походження

## Надані користувачем матеріали

- `File_Integrity_Monitoring.pdf`: визначення baseline (стор. 3), режими перевірки
  (стор. 4), властивості файлів (стор. 7), baseline/logging/alerts (стор. 8),
  динамічні файли та кількість попереджень (стор. 10).
- `fim-rust.zip` / попередній `main.rs`: вихідна реалізація, HTML-шаблон та календар.
- `SB prednáška 2026 - 02.pdf` присвячено стеганографії; для змін FIM він не був
  джерелом технічних вимог.

## Документація для інженерних доповнень

- Linux openat2: https://man7.org/linux/man-pages/man2/openat2.2.html
- Linux renameat2/RENAME_EXCHANGE: https://man7.org/linux/man-pages/man2/renameat2.2.html
- Rust process groups: https://doc.rust-lang.org/std/os/unix/process/trait.CommandExt.html
- notify 8.2 API та обмеження: https://docs.rs/notify/8.2.0/notify/
- notify Linux event mapping/cookies: https://docs.rs/notify/8.2.0/src/notify/inotify.rs.html
- notify symlink configuration: https://docs.rs/notify/8.2.0/notify/struct.Config.html
- Rust installation: https://rust-lang.org/tools/install/

Календар успадковано з попереднього проєкту без нового фактчеку іменин.
Зазначене там джерело: https://www.culture.gov.sk/storage/2020/03/Oficialne-kalendarium_2025.pdf
Це не підтвердження редакції 2026 року.
